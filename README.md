## 📋 Overview

Mammography-based binary classifier for breast cancer detection trained on the RSNA Breast Cancer Detection competition dataset. Optimized for high recall to minimize false negatives in screening scenarios.

## 🎯 Results

| Metric | Value |
|--------|-------|
| **Accuracy** | **93%** |
| Dataset | RSNA Mammography |
| Architecture | EfficientNetB3 |
| Task | Binary (Cancer / No Cancer) |

## 🗂️ Dataset

RSNA Breast Cancer Detection — available on Kaggle.
[![Kaggle](https://img.shields.io/badge/Kaggle-Dataset-20BEFF?style=flat-square&logo=kaggle)](https://www.kaggle.com/yousefmohamedjoe)

## 🔧 Key Techniques

- ✅ **Precision-recall** optimization for clinical screening
- ✅ Clinical-grade DICOM image preprocessing
- ✅ Heavy augmentation for mammography images
- ✅ Two-phase EfficientNetB3 fine-tuning
- ✅ Threshold tuning for high-sensitivity output
